# Private data folder (local only)

Everything in this folder except this README is ignored by git. Put CK+ and KDEF here if you like:

- `ckplus/`  original CK+ folders (do not commit)
- `kdef/`    original KDEF folders (do not commit)

You can also keep them outside the repository and pass the path to the scripts. Outside the repo is safer, because nothing in the working tree can be staged by accident.

Never upload these folders to GitHub, Colab notebooks that are shared, or any chat. Only numbers and charts without faces leave your machine.
