# Responsible use

- The labels in these datasets describe posed or annotated facial expressions. They are not verified inner states. A model that predicts "happiness" has predicted a label for a pattern of pixels or landmarks.
- Datasets differ in who appears in them and how the images were made. Results on one dataset should not be assumed to hold for other people, cameras or lighting. The demo has not been tested across these.
- Webcam input in the demo stays in the browser. Do not point the demo at other people without their agreement.
- Some places restrict or prohibit emotion recognition in some settings, such as workplaces and schools. This repository gives no legal advice. Check the rules that apply to you before using anything like this in a product.
- Do not use this code or model to make decisions about people.
