About the model

The model file, model.onnx, comes from the repository's GitHub release. Only the FP32 file is published: the INT8 version failed its test (accuracy 0.047 against 0.705 for FP32), so it is not used. The model is a MobileNetV3-small trained on FER2013 with FER+ labels.

Weakest classes on the FER2013 PrivateTest split, by recall: contempt (0.481), fear (0.516) and neutral (0.599). Expect these three to be wrong more often. All numbers: measured (host CPU), from results/study3_ferplus.json. FER2013 has no subject IDs, so they are optimistic. On JAFFE, which the model was not trained on, accuracy was 0.380 (measured (host CPU), results/study3_ood_jaffe.json).
